# TaskLane

TaskLane is a visual task board for organising work across To Do, In Progress, In Review and Done. Users can create, edit and move tasks, set priorities and due dates, add comments, and track progress with a summary. Supabase guest accounts keep each user's tasks private.

## Supabase setup

This stage connects the board to Supabase Auth and Postgres. It uses anonymous guest sessions, so visitors do not need an email or password.

### 1. Create the Supabase project

Create a project in Supabase. In the project dashboard, open **Authentication** and enable **Anonymous Sign-Ins**.

### 2. Create the database tables

Open **SQL Editor**, create a new query, paste the contents of `supabase-schema.sql`, and run it. This creates the `tasks` and `comments` tables, indexes, grants, and row-level security policies.

### 3. Add the browser connection values

In your project's **Connect** dialog, copy the Project URL and publishable key (or the older `anon` key if that is what your dashboard shows). Open `supabase-config.js` and replace the two placeholder strings.

The publishable/anon key is intended for browser use. Never put a service-role or secret key in this file.

### 4. Run the app

Open the `tasklane` folder in VS Code and start `index.html` with Live Server. On the first visit, the app creates an anonymous user. Supabase Auth keeps that session in this browser so the same guest sees their saved tasks when they return.

The app loads tasks and their comments from Supabase. Creating, editing, deleting, commenting, and moving a task between columns writes to the database. The database policies restrict each guest to their own tasks and comments.

## Data tables

- `tasks`: title, status, description, priority, due date, owner user ID, and creation time.
- `comments`: task ID, comment body, owner user ID, and creation time.

Task IDs, user IDs, and timestamps are generated by Supabase or the active guest session. They are not entered in the task form.

## Guest account limitation

An anonymous account is tied to this browser's saved session. Clearing browser storage or switching devices creates a different guest account, which cannot reopen the earlier guest's tasks.
